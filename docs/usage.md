# SATLI lite 使用指南

首次安装请先阅读 [README](../README.md#前置要求)。本指南说明日常操作、更新、备份和故障处理。

## 打开译本管理

从 Steam 左上角“Steam”菜单打开 Millennium，再进入 SATLI lite 设置页，点击“管理译本”。Steam 库存游戏页中的“成就翻译”按钮也可打开同一界面，并直接定位到该游戏。

管理窗口较宽时，左侧为游戏列表，右侧为译本详情。窗口较窄时，选择游戏后进入详情，使用左上角返回按钮回到列表。列表与详情可分别滚动。

右上角“刷新列表”会重新读取社区译本、库存归属和本机安装情况。新购买或刚安装游戏后，可用此按钮刷新。

### 查找游戏

搜索框接受游戏名或 App ID。App ID 是 Steam 为游戏分配的数字编号，例如商店地址 `https://store.steampowered.com/app/620/` 中的 `620`。

| 列表范围 | 显示内容 |
| --- | --- |
| 我的库存 | Steam 库存中已有社区译本或本地译本的游戏，包含未安装的游戏 |
| 社区译本 | 全部已收录游戏，以及已有本地译本的游戏 |
| 已下载 | 已在本机下载或导入并应用过译本的游戏，包含当前停用的译本 |

“只看已安装”可与以上任一范围组合使用。要查找未安装的游戏，请关闭这一筛选。

列表数量不是 Steam 库存的总游戏数。未被翻译库收录、也没有本地译本的游戏不会出现在列表中。

## 选择、应用与停用译本

选中游戏后，在“译本”中选择需要的版本，再选择语言。不同版本可能有不同的翻译风格、解锁条件说明或语言范围，请同时查看版本说明和“翻译来源”。没有其他版本的游戏只提供一个选项。

点击“预览译本”可查看成就名称、描述和可用的英文参考，也可按文字或成就 ID 搜索。预览会获取译本文件，但不会启用该译本。

- 首次应用时，点击“下载并应用”。
- 已有译本时，点击“应用所选译本”，切换到当前所选的版本与语言。
- 仅选择下拉框中的选项，不会改变当前正在使用的译本。

每个游戏同时使用一个译本和一种语言。详情中的本地译本说明显示当前实际使用的版本；它可能与尚未应用的下拉框选项不同。

关闭游戏详情中的翻译开关，可让这个游戏恢复显示原文，并保留已下载文件。插件设置页的“启用成就翻译”是全局开关，关闭后暂停所有游戏的翻译；重新打开后仍按各游戏原有开关生效。

文字替换用于 Steam 中的成就页面、库存与活动、好友成就、会话历史及成就通知。它不翻译游戏内的菜单或对白，不修改游戏文件、存档、成就解锁状态、进度和图标。部分已显示的文字受 Steam 缓存影响，应用或停用后需切换页面，必要时重启 Steam。

### 恢复上一版

下载并应用、切换译本、编辑或导入后，可在游戏详情中点击“恢复上一版”，回到上一次保存的本地状态。没有历史记录时，这个按钮不可用。

每个游戏保留最近十二次状态记录。恢复范围仅限本机保存过的状态；需要长期保留某份译本时，请使用“导出 JSON”另行备份。

## 批量下载与更新译本

在插件设置页的“批量翻译”区域操作。批量下载使用各游戏的**默认译本**和设置页中的**默认下载语言**；需要其他版本的游戏请在“管理译本”中单独选择。

1. 先在“翻译”区域选择默认下载语言，初始值为简体中文。
2. 点击“识别库存游戏”，将库存中可下载的游戏 App ID 填入输入框。识别包含未安装的游戏，只加入翻译库已收录、默认译本可下载且支持所选语言的游戏。
3. 检查输入框，可添加或移除 App ID。手动输入时用空格或逗号分隔，例如 `620, 105600`。
4. 点击“批量下载”，查看下方的成功、失败和跳过数量。

不提供所选语言或缺少下载文件的游戏会被跳过。识别结果少于“我的库存”数量时，请检查默认语言和默认译本是否可用。

批量下载会应用默认译本，可能替换这些游戏当前选择的其他版本或本地编辑。已有自定义译本时，请先从输入框移除对应 App ID，或导出备份。

“更新已下载译本”只检查**已启用且没有本地编辑**的译本，保留各游戏当前的译本选择与语言；没有更新的项目会跳过。这一操作不使用 App ID 输入框。

下载过程中可点击“停止后续下载”。当前正在进行的单项请求会完成或超时，剩余项目不再开始。单个游戏下载失败不会撤销其他游戏已经完成的操作。

## 编辑、导入与导出

### 编辑已应用的译本

1. 在“管理译本”中选择已下载的游戏，点击“查看 / 编辑”。
2. 搜索需要修改的成就，点击该成就旁的编辑按钮。
3. 修改“成就名称”或“成就描述”，点击“保存修改”；点击“取消”则放弃这一项尚未保存的输入。

编辑作用于当前已应用语言，只保存在本机，不会提交到社区翻译库。自动更新和“更新已下载译本”会跳过含本地编辑的译本。

“预览译本”显示的是社区版本；编辑本地内容应使用“查看 / 编辑”。再次点击“应用所选译本”会用所选社区译本替换当前本地编辑，操作前可先导出备份。

### 导出与导入 JSON

在游戏详情中点击“导出 JSON”，保存当前本地译本，文件名为 `UserGameStatsSchema_<App ID>.json`。导出的文件包含本地修改，可用于备份或转移到另一台设备。

在管理窗口底部点击“导入本地译本”，选择 SATLI lite 导出的 JSON，或翻译库提供的兼容 JSON。导入成功后会应用文件中的译本并选中对应游戏；默认下载语言在文件中不可用时，使用文件提供的第一种语言。

导入支持不超过 32 MiB 的兼容 JSON 文件。普通文本、任意 JSON、CSV、BIN 和 ZIP 不能作为本地译本直接导入；将扩展名改为 `.json` 不会转换文件格式。需要制作完整 BIN 或向社区投稿时，可使用 [SATLI](https://github.com/GaBoron/SATLI) 并参考 [翻译库说明](https://github.com/GaBoron/steam-achievement-translation-library)。

导入会替换该游戏当前应用的译本。文件来自其他人时，建议导入后用“查看 / 编辑”核对内容；已有本地编辑应先导出备份。

## 自动更新与手动更新

社区译本更新和插件更新分别控制，两者互不代替。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 启用成就翻译 | 开启 | 控制所有游戏的翻译显示 |
| 默认下载语言 | 简体中文 | 用于批量下载及单个游戏的初始语言选择，不会更改已应用译本的语言 |
| 自动更新社区译本 | 关闭 | 更新已启用且没有本地编辑的社区译本，保留当前译本选择与语言 |
| 自动更新 SATLI lite | 开启 | 获取并安装本项目的新版插件，重启 Steam 后生效 |

插件启动时及运行期间每六小时刷新翻译库，并按开关设置检查相应更新。关闭“自动更新社区译本”仍可刷新目录和手动下载；停用的游戏或含本地编辑的译本不会被自动更新。

### 更新插件

自动更新开启时，新版安装完成会提示“重启 Steam 后生效”。插件不会自行退出或重启 Steam，请从 Steam 菜单选择“退出”后重新启动。

手动检查时，在“插件更新”中点击“检查更新”；发现新版后点击“安装”按钮。也可通过“发布说明”查看版本变化。

网络或文件写入权限导致自动更新失败时，可按 [README 安装步骤](../README.md#安装) 下载新的 `satli-lite.star`，完全退出 Steam 后替换原文件，再启动 Steam。保持文件名为 `satli-lite.star`，本地设置和译本无需重新下载。

插件更新从本项目的正式 GitHub Release 获取；翻译库镜像不会改变插件更新来源。`update.json` 由插件读取，手动安装只需要 `.star` 文件。

## 网络与翻译库来源

默认使用 GitHub 上的社区翻译库。获取目录和译本需要访问 `raw.githubusercontent.com`，检查插件版本需要访问 `api.github.com`，下载插件更新还需要访问 GitHub 的发布文件服务。仅能打开 GitHub 网页并不代表这些请求都能成功。

插件网络代理沿用 Millennium 设置。使用代理时，请先确认 Millennium 的网络与代理设置可用，再重试下载。

需要使用镜像时，在插件设置页展开“翻译库来源”，将镜像根目录填入“HTTPS 镜像目录”，点击“保存并刷新”。镜像必须提供与社区翻译库兼容的目录和译本文件；不要填写某个游戏的文件地址、GitHub 网页地址，或包含账号、密码、查询参数的链接。

清空镜像输入框并点击“保存并刷新”，即可恢复 GitHub 来源。镜像由其维护者更新，可能与社区最新内容存在时间差。

网络不可用时，已应用的本地译本仍可使用。获取新译本、新版本或最新列表需要恢复网络连接。

## 常见问题

### 安装与启动问题

**找不到 Steam 安装目录**

Windows 中可右键 Steam 快捷方式，打开“属性”查看目标路径，或选择“打开文件所在的位置”。需要找到包含 `steam.exe` 的目录，不是某个游戏的安装目录。也可参照 [Millennium 官方查找指南](https://docs.steambrew.app/users/guides/finding-steam)。

**“Steam”菜单中没有 Millennium**

先确认 Millennium 已安装到当前使用的 Steam，并完全退出、重新启动 Steam。仍没有入口时，请按 [Millennium 官方故障排查](https://docs.steambrew.app/users/getting-started/troubleshooting) 检查；SATLI lite 需要 Millennium 正常运行后才能加载。

**Millennium 中没有 SATLI lite**

确认下载的是 Release 的 `satli-lite.star`，文件位于实际 Steam 目录下的 `millennium\plugins`，而不是源码 ZIP、游戏库、主题目录或额外嵌套的文件夹。检查文件扩展名是否被隐藏或改成了 `.txt`，并在放入文件后完全重启 Steam。

其他系统请按 [Millennium 官方安装说明](https://docs.steambrew.app/users/getting-started/installation) 安装宿主，并使用该系统对应的 [插件目录](https://docs.steambrew.app/users/getting-started/structure)。Linux 的 Flatpak、Snap 版 Steam 和 ARM 系统不在 Millennium 官方支持范围内。

**看不到库存页的“成就翻译”按钮**

确认插件已启用，先打开一个游戏的库存详情页。按钮仍未显示时，从 Millennium 的 SATLI lite 设置页点击“管理译本”；两个入口提供相同的管理功能。

### 游戏数量或显示结果不符

**识别结果比实际库存少**

插件只列出已有译本的游戏，不显示库存中的所有应用。检查是否开启“只看已安装”、是否有搜索关键词；批量识别还要求默认译本支持默认下载语言。打开 Steam 库存后点击“刷新列表”，再重新识别。

**找不到某个游戏或某种语言**

切换到“社区译本”，使用 App ID 搜索。游戏未收录时可提交翻译请求；已收录但没有所需语言或版本时，只能使用当前提供的选项，也可导入兼容的本地译本。

**应用成功后仍显示原文**

检查全局“启用成就翻译”和该游戏的翻译开关均已开启，详情中当前语言与译本符合预期。下拉框选项更改后还需点击“应用所选译本”。切换到其他游戏再返回；仍未刷新时完全重启 Steam。若只有部分成就未翻译，检查译本是否包含对应内容，以及社区是否已标记过期。

**社区标记译本过期或可能不生效**

游戏新增或调整成就后，旧译本可能缺少内容。先刷新列表并检查更新；没有新版时，可使用其他译本、暂时停用，或通过“报告译本问题”告知维护者。Steam 客户端更新也可能影响文字显示，此类问题请反馈到插件仓库。

### 下载、导入或更新失败

**下载失败，出现 HTTP 403、其他 HTTP 状态或网络请求失败**

检查 Millennium 网络与代理设置，以及翻译库镜像是否可用。HTTP 403 也可能是访问限制，稍后重试或使用有效的翻译库镜像；镜像只能改善译本请求，不能代替 GitHub 插件更新服务。反复失败时展开“技术详情”，保留错误信息用于反馈。

**提示译本版本不匹配、下载文件缺失或内容无效**

点击“刷新列表”后重新选择并应用。使用镜像时，其目录与文件可能未同步，可恢复 GitHub 来源重试。不要修改下载文件中的版本或游戏编号来绕过提示；仍失败时提交游戏 App ID、所选译本和错误信息。

**导入失败**

确认文件来自 SATLI lite 导出或兼容的社区翻译 JSON，大小不超过 32 MiB，且未被其他编辑器损坏。BIN、CSV、ZIP 不能直接导入。错误详情可帮助判断文件格式或语言是否符合要求。

**插件更新提示无法读取、备份或替换文件**

确认安装文件名仍为 `satli-lite.star`，所在目录允许写入，且文件没有被其他程序占用。先完全退出 Steam，再按安装步骤手动替换；不必删除译本数据目录。

## 数据备份与卸载

Windows 默认安装时，本地数据位于：

```text
C:\Program Files (x86)\Steam\millennium\config\satli-lite\
```

Steam 安装在其他位置时，使用对应的 `millennium\config\satli-lite`。该目录包含设置、已下载译本、本地修改、历史记录和自动更新前保留的旧插件包。

备份前完全退出 Steam，再复制整个 `satli-lite` 数据目录。恢复时同样先退出 Steam，将备份放回对应位置；为保留现有数据，恢复前先将当前目录另行备份。不要在 Steam 运行时手动编辑其中的状态文件。

只需要保存某个游戏的译本时，使用“导出 JSON”即可。停用插件或替换安装包不会主动清除数据；历史和旧包也不会自动清理。

卸载时，先在 Millennium 中停用 SATLI lite，完全退出 Steam，再将插件目录中的 `satli-lite.star` 移入回收站。数据目录可保留以便重新安装；不再需要时，备份后将对应的 `satli-lite` 数据目录也移入回收站。不要移除整个 Millennium 或其他插件的目录。

## 反馈与翻译请求

- 插件安装、界面、下载或更新问题：使用设置页“反馈入口”，或 [提交插件问题](https://github.com/GaBoron/SATLI-lite/issues/new)。
- 翻译错误、缺漏或游戏更新后的过期内容：使用游戏详情中的“报告译本问题”，或 [提交译本报告](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=outdated_report_zh.yml)。
- 未收录游戏：向翻译库 [提交翻译请求](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=translation_petition_zh.yml)。

反馈时注明 Steam 与 Millennium 版本、SATLI lite 版本、游戏 App ID、所选译本和语言，并描述出现问题的操作。可以附上界面截图和“技术详情”；窗口打不开或插件无法加载时，可在 Millennium 的日志中查找 SATLI lite 对应的错误。

游戏列表在本机读取，网络请求用于翻译库和插件更新。日志由 Millennium 管理，记录操作起止和错误，不记录成就文本、凭据或反馈内容。反馈入口只打开表单，内容由用户填写并提交；提交前请检查截图与日志是否包含不希望公开的个人信息。
